Disconnect handling:
- Host sends an explicit leave on its authenticated control connection.
- Relay acknowledges, removes the room, and sends data-channel EOF before
  closing WebSockets. This avoids waiting for proxy close propagation.
- Control cleanup runs outside the game rendering thread and is bounded.

Scope and remaining limits:
- Public integration used one Windows runner through the real Render relay.
  Separate player PCs / internet lines and manual Windows controls are unverified.
- Free service can sleep after 15 minutes idle; startup may take about one minute.
  The game waits up to 75 seconds and allows cancellation.
- Relay restarts end rooms; room host must remain online. Saves stay on player PCs.
- No cloud accounts or central save authority were added. Host authority and
  local save-integrity limitations remain documented in SECURITY_AND_SAVES.md.
- Windows release assets are generated by the existing tag-triggered workflow;
  its live status can be checked under GitHub Actions for tag v9.5.0.
